### Added

- Ctrl+click from a Vue component tag in a Blade view to its `.vue` file.
- Colouring of recognised component tags, without the "Unknown HTML tag" warning.
- Inspection for component tags that aren't registered in any Vue app.
- Find Usages of a `.vue` file lists the Blade views using its tag.
