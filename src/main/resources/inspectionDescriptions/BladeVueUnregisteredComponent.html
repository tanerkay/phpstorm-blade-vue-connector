Reports tags in Blade views that look like Vue components (a hyphenated or PascalCase name that isn't an HTML, SVG or MathML element) but aren't registered in any Vue app.

Registrations are read from app.component(...), Vue.component(...) and components: {} on createApp(...) or new Vue(...) in the project's JavaScript and TypeScript files. <x-...>, livewire: and flux: tags are never reported.

To avoid false positives, nothing is reported:

  • in projects without any component registrations;
  • when components are also registered in a way that can't be read, such as a loop over a library's exports (unless enabled below);
  • for tags without a same-named .vue file, when Vue plugins that may register components are installed with .use() (unless enabled below);
  • in views under the excluded paths, by default resources/views/vendor/**.

Use the quick-fix or the ignored tags option for tags provided by a component library, e.g. ^b-.
